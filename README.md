# CalorieCalcNow

**Fast, Accurate Calorie Calculator for Fitness & Nutrition Tracking**

A modern, mobile-responsive web application built with Next.js and Tailwind CSS that helps users calculate daily calorie intake based on their personal metrics and fitness goals.

## Features

✅ **Fast Calculations** - Instant calorie estimates using Harris-Benedict and Mifflin-St Jeor equations
✅ **Mobile Responsive** - Works perfectly on desktop, tablet, and mobile devices
✅ **SEO Optimized** - Structured data, meta tags, and sitemap for organic search visibility
✅ **Modern Design** - Clean, intuitive user interface with Tailwind CSS
✅ **Multiple Goals** - Support for weight loss, maintenance, and muscle gain
✅ **Email Capture** - Newsletter signup for email marketing
✅ **Monetization Ready** - Ad placements and affiliate opportunities

## Tech Stack

- **Framework**: Next.js 14
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Deployment**: Vercel
- **Analytics**: Google Analytics ready

## Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation

```bash
git clone https://github.com/igetmoneyhere/caloriecalcnow.git
cd caloriecalcnow
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
npm start
```
